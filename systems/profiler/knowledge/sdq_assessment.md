# SDQ 长处与困难问卷 (Strengths and Difficulties Questionnaire)

**来源**: Robert Goodman, 1997 | 全球使用最广的儿童行为筛查工具
**适用年龄**: 4-17 岁 | 有父母版、教师版、自评版（11岁以上）
**授权**: 教育/研究用途免费 (sdqinfo.org)

## 量表结构
25 题，每题 3 级评分：不符合(0) / 有点符合(1) / 完全符合(2)
分为 5 个分量表，每个分量表 5 题。

## 完整题目与维度对应

### 分量表 1：情绪症状 (Emotional Symptoms)
评估焦虑、恐惧、躯体化等内化问题。
| 题号 | 原始题目 | 对话改编建议 |
|------|---------|-------------|
| E1 | 我经常头疼、肚子疼或不舒服 | "上学前有没有觉得肚子不太舒服的时候？" |
| E2 | 我经常担心很多事情 | "你睡觉前脑子里会不会转好多念头？" |
| E3 | 我经常不开心、沮丧或想哭 | [观察对话情绪基调，不直接问] |
| E4 | 在新的环境里我会紧张，容易失去信心 | "如果换到一个新班级，你觉得你会怎么样？" |
| E5 | 我有很多害怕的东西，容易受惊吓 | "你有特别怕的东西吗？比如黑暗或者虫子？" |

### 分量表 2：品行问题 (Conduct Problems)
评估冲动控制、规则意识、攻击性。
| 题号 | 原始题目 | 对话改编建议 |
|------|---------|-------------|
| C1 | 我经常发很大的脾气 | "你生气的时候一般会怎么做？" |
| C2 | 我通常会照别人说的做 (反向计分) | "老师布置的事情你一般会怎么做？" |
| C3 | 我经常打架 | "你跟同学有没有闹过矛盾？后来怎么解决的？" |
| C4 | 我经常被人说撒谎或骗人 | [通过故事投射法间接探测] |
| C5 | 我会拿不属于自己的东西 | [不直接问，通过价值观场景探测] |

### 分量表 3：多动/注意力不集中 (Hyperactivity/Inattention)
评估注意力持续性、活动水平、冲动性。
| 题号 | 原始题目 | 对话改编建议 |
|------|---------|-------------|
| H1 | 我坐不住，经常动来动去 | "上课的时候你能一直坐着不动吗？还是会想动一动？" |
| H2 | 我经常坐立不安或扭来扭去 | [观察对话中是否频繁切换话题] |
| H3 | 我容易分心，很难集中注意力 | "做作业的时候你能一直做还是会想玩一会儿？" |
| H4 | 我做事之前会先想想 (反向计分) | "如果遇到一道新题，你是先想再写，还是直接写？" |
| H5 | 我做事善始善终，注意力很好 (反向计分) | "你开始画一幅画，一般会画完还是画一半去做别的了？" |

### 分量表 4：同伴关系问题 (Peer Relationship Problems)
评估社交孤立、被欺负、同伴接纳度。
| 题号 | 原始题目 | 对话改编建议 |
|------|---------|-------------|
| P1 | 我更喜欢一个人待着 | "下课了你喜欢跟同学一起玩还是自己待着？" |
| P2 | 我有一个或更多好朋友 | "你在学校有最好的朋友吗？你们一般一起干什么？" |
| P3 | 同龄人一般都喜欢我 (反向计分) | "你觉得班上同学喜欢跟你玩吗？" |
| P4 | 其他小朋友会欺负我 | [用第三人称投射法: "你们班有没有被欺负的同学？"] |
| P5 | 我跟大人相处比跟同龄人好 | "你觉得跟大人聊天容易还是跟小朋友聊天容易？" |

### 分量表 5：亲社会行为 (Prosocial Behavior)
评估助人、共情、分享、友善等积极品质。
| 题号 | 原始题目 | 对话改编建议 |
|------|---------|-------------|
| S1 | 我会关心别人的感受 | "如果你看到一个同学哭了，你会怎么做？" |
| S2 | 我愿意跟别人分享 | "如果你有两个冰淇淋但朋友没有，你会怎么办？" |
| S3 | 如果别人受伤、难过或生病，我会帮忙 | "同学不舒服的时候你一般会怎么做？" |
| S4 | 我对比我小的孩子很好 | "你有弟弟妹妹吗？你平时怎么跟他们相处？" |
| S5 | 我经常主动帮助别人 | "你在学校会主动帮老师或同学做事吗？" |

## 评分方法
- **总困难分 (Total Difficulties Score)**: 情绪 + 品行 + 多动 + 同伴 = 0~40 分
- **亲社会分**: 单独计算，0~10 分
- 注意：C2, H4, H5, P3 为反向计分题

## 分数解读 (自评版参考常模)
| 等级 | 总困难分 | 解读 |
|------|---------|------|
| 正常 | 0-15 | 行为情绪发展良好 |
| 边缘 | 16-19 | 需关注，建议进一步观察 |
| 异常 | 20-40 | 建议专业评估 |

## AI 对话评估策略
1. **不要一次性问 25 道题**！分散在 5-8 轮对话中自然嵌入
2. 每轮对话最多触及 1-2 个维度
3. 优先用投射法和故事续写法替代直接提问
4. 对于敏感题目（品行问题），绝对不要直接问
5. 根据孩子的兴趣话题动态调整措辞
