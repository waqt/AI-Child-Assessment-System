# Gardner 多元智能评估指南 (Multiple Intelligences Assessment)

**来源**: Howard Gardner (1983) "Frames of Mind"
**适用年龄**: 6-12 岁
**说明**: 多元智能不是"你有或没有"，而是"哪些更强"。每个孩子都拥有全部 8 种智能，只是程度不同。

## 八种智能及其对话评估策略

### 1. 语言智能 (Linguistic Intelligence) — "语言达人"
**能力**: 善于用语言表达、理解复杂指令、讲故事、编笑话

**高智能信号**:
- 词汇量大，会用成语或比喻
- 喜欢编故事、说笑话
- 善于表达自己的想法

**对话探测**:
- 观察孩子在对话中的用词丰富度和表达清晰度
- "你能给我讲一个你编的小故事吗？什么故事都行"
- "你喜欢看书吗？最喜欢什么类型的？"

### 2. 逻辑-数学智能 (Logical-Mathematical Intelligence) — "逻辑达人"
**能力**: 善于推理、发现规律、解决问题、量化思考

**高智能信号**:
- 喜欢问"为什么"
- 对数字、规律敏感
- 喜欢策略游戏（如棋类）

**对话探测**:
- "1, 3, 5, 7, 下一个是几？你怎么想到的？"
- "如果一只蜗牛每天爬3米，滑下2米，那5天后它爬了多高？"
- 注意观察孩子是用直觉还是逻辑推理来解决问题

### 3. 空间智能 (Visual-Spatial Intelligence) — "空间达人"
**能力**: 善于想象、绘画、搭建、理解方位

**高智能信号**:
- 喜欢搭积木、画画、拼图
- 在 Minecraft 中能建造复杂建筑
- 方向感好

**对话探测**:
- "你觉得一个正方形对折会变成什么形状？再对折呢？"
- "如果让你画一幅你家的俯视图（从天上往下看），你能画出来吗？"
- "你在我的世界里建房子时，脑子里会先想好样子吗？还是边搭边想？"

### 4. 肢体-动觉智能 (Bodily-Kinesthetic Intelligence) — "运动达人"
**能力**: 善于控制身体、动手操作、通过身体学习

**高智能信号**:
- 运动协调性好
- 喜欢动手做实验
- 坐不住但做手工时特别专注

**对话探测**:
- "你最擅长什么运动？"
- "你喜欢动手做东西吗？比如拼模型、做手工？"
- "学一个新东西的时候，你是喜欢看别人做还是自己上手试？"

### 5. 音乐智能 (Musical Intelligence) — "音乐达人"
**能力**: 对节奏、音高、旋律敏感，善于感知和创作音乐

**高智能信号**:
- 经常哼歌、打节拍
- 能记住歌曲旋律
- 对环境中的声音敏感

**对话探测**:
- "你喜欢听音乐吗？最喜欢什么歌？"
- "你能跟着节拍拍手吗？来试试——哒哒 哒哒哒 哒"
- "你上课的时候会不自觉地哼歌或者打拍子吗？"

### 6. 人际智能 (Interpersonal Intelligence) — "社交达人"
**能力**: 善于理解他人的情绪和动机，善于沟通和合作

**高智能信号**:
- 朋友多，善于调解矛盾
- 能察觉别人的情绪变化
- 在团队中自然成为领导者

**对话探测**:
- "你在朋友中一般是出主意的人还是跟着玩的人？"
- "如果两个好朋友吵架了，你会怎么帮忙？"
- "你觉得你能看出来别人是不是不开心吗？怎么看出来的？"

### 7. 自省智能 (Intrapersonal Intelligence) — "内省达人"
**能力**: 善于认识自己、理解自己的情绪和动机

**高智能信号**:
- 有自己的思考方式
- 知道自己的优缺点
- 独立性强，有主见

**对话探测**:
- "你觉得你自己是什么样的人？"
- "你做错了一件事之后，一般会想很久吗？"
- "你有没有自己特别想做的事情？为什么想做？"

### 8. 自然智能 (Naturalist Intelligence) — "自然达人"
**能力**: 善于观察和分类自然界事物，对动植物敏感

**高智能信号**:
- 喜欢动物、植物
- 善于观察细节和分类
- 对天气、季节变化敏感

**对话探测**:
- "你喜欢什么动物？为什么？"
- "你有没有养过小动物或种过植物？"
- "如果给你一堆不同的树叶，你会怎么把它们分类？"

## 与学习风格的映射关系
| 智能类型 | 最佳学习方式 | 数学教学建议 |
|---------|------------|------------|
| 语言智能 | 讲述、讨论、阅读 | 用故事讲解应用题 |
| 逻辑-数学 | 推理、实验、分类 | 直接给挑战性题目 |
| 空间智能 | 画图、搭建、想象 | 用图形和图表辅助 |
| 肢体-动觉 | 动手操作、实验 | 用实物教具（积木、计数棒） |
| 音乐智能 | 节奏、韵律、歌曲 | 乘法口诀编成歌 |
| 人际智能 | 合作、讨论、教别人 | 小组互教互学 |
| 自省智能 | 独立思考、反思 | 给独立探索时间 |
| 自然智能 | 观察、分类、对比 | 用自然现象引入数学 |
