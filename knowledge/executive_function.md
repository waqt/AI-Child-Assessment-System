# 儿童执行功能评估指南 (Executive Function Assessment)

**理论基础**: Miyake et al. (2000) 执行功能三因素模型
**适用年龄**: 8-12 岁（前额叶快速发育期）
**参考工具**: BRIEF-2, CEFI, Stroop Test, Trail Making Test

## 一、执行功能三大核心维度

### 1. 工作记忆 (Working Memory)
在头脑中暂时保持和操纵信息的能力。

**行为标记（正向）**:
- 能记住多步骤指令并按顺序执行
- 做数学应用题时能同时追踪多个条件
- 听故事后能复述关键情节

**行为标记（困难）**:
- 忘记刚才说的话或要做的事
- 做题时丢条件（例如忘记"还剩多少"）
- 需要反复提醒才能完成任务

**对话探测**:
- 讲一个包含 3-4 个数字的小故事，最后问一个需要综合这些数字的问题
- "我来说 3 个数字：5, 3, 7。你能倒着说回来吗？" (数字倒序任务)
- 故事复述："小明早上吃了2个包子，中午吃了3个饺子，晚上吃了1碗面。他一天吃了几样东西？分别是什么？"

### 2. 抑制控制 (Inhibitory Control)
控制冲动、抵制干扰、抑制不恰当反应的能力。

**行为标记（正向）**:
- 能等待轮到自己再说话
- 能抵制诱惑先完成任务
- 思考后再行动

**行为标记（困难）**:
- 经常打断别人说话
- 不假思索就回答（然后发现答案错了）
- 明知道不应该但还是做了

**对话探测**:
- 观察孩子是否等你说完再回答
- "我说水果你就拍手，但如果我说蔬菜你就不要拍。准备好了吗？苹果！...西红柿！...香蕉！" (Go/No-Go 任务变体)
- "我现在说一个数字，如果是单数你说'嘿'，双数你什么都不说：3...6...5...8...7"

### 3. 认知灵活性 (Cognitive Flexibility)
在不同任务、规则或思维方式之间灵活切换的能力。

**行为标记（正向）**:
- 遇到死路能换方法
- 能理解同一事物的不同视角
- 适应规则变化时不焦虑

**行为标记（困难）**:
- "卡住"在一种解题方法上
- 日程变化时情绪波动大
- 坚持自己的方法不听建议

**对话探测**:
- "如果你做一道题的时候，发现你学的方法行不通，你会怎么办？"
- "如果游戏规则突然变了，你是觉得好玩还是觉得烦？"
- 数字切换任务："我说一个规则——大于5的数字你加1，小于等于5的数字你减1。7？...3？...5？...9？"

## 二、综合评估指标

### 日常行为观察清单（改编自 BRIEF-2）
| 行为 | 对应维度 | 如何在对话中探测 |
|------|---------|----------------|
| 做事有计划 | 计划/组织 | "你做数学作业是按顺序做还是挑着做？" |
| 整理物品 | 组织 | "你的书包里面是什么样的？" |
| 时间管理 | 监控 | "你觉得做一页数学作业大概要多久？" |
| 情绪控制 | 情绪调节 | "做不出题的时候你会着急吗？着急了怎么办？" |
| 任务启动 | 启动 | "放学回家你是先做作业还是先玩？" |
| 完成任务 | 完成监控 | "你有没有做到一半就不想做了的时候？" |

## 三、年龄发展参考基线 (8-10 岁)
- 工作记忆：应能处理 3-4 步指令、倒背 3-4 位数字
- 抑制控制：基本能等待轮流，但在兴奋时仍可能冲动
- 认知灵活性：能在 2-3 种规则间切换，但速度较慢是正常的
- 注意：这些能力仍在发展中，8岁表现弱于10岁是正常的，不要过早下结论
