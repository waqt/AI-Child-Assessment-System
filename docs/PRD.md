## 一、项目愿景

打造一个**真正懂孩子的 AI 数学老师**。它不是一个冷冰冰的刷题工具，而是一个能够：
1. **读懂孩子**：通过自然对话，像教育心理学专家一样精准画像孩子的个性、行为模式、学习方式和数学能力。
2. **因材施教**：根据每个孩子独特的画像，动态调整教学方式、题目难度和沟通语气。
3. **长期陪伴**：拥有持久记忆，记住每次对话的内容和孩子的成长变化。

## 二、系统功能模块

### 模块 1：学生画像系统 ✅ 已完成

> **核心目标**：通过自然对话，无感地完成对孩子的教育基线评估。

#### 1.1 四大核心评估维度

| 维度 | 评估内容 | 理论基础 |
|------|---------|---------|
| **个性 (Personality)** | 内向/外向、沉稳/急躁、好奇心强弱 | Big Five 五大人格 |
| **行为特征 (Behavioral Traits)** | 遇挫反应、求助模式、情绪稳定性、延迟满足 | Grit 坚毅力 + 成长型思维 |
| **学习方式 (Learning Style)** | 视觉/听觉/动觉/读写偏好 | VARK 学习风格理论 |
| **数学能力 (Math Capability)** | 数感、计算、逻辑推理、空间想象 | 布鲁姆认知分类 + 课标 |

#### 1.2 评估机制

- **假设-验证 (Hypothesis Testing)**：观察到线索 → 记录假设 → 换情境交叉验证 → 确认结论
- **AB Test 交叉验证**：同一维度至少经过 2 次不同情境的测试才能确认
- **去伪存真技巧**：第三人称投射法、故事续写法、强制双正选择、矛盾追踪、元语言线索分析
- **Chain of Thought 专家推理**：AI 每次回复前先写内心分析过程（家长可查看）

#### 1.3 专家知识库

内置 7 大理论模块（`expert_knowledge.py`）：
1. VARK 学习风格理论
2. 成长型思维 vs 固定型思维 (Carol Dweck)
3. 坚毅力 Grit (Angela Duckworth)
4. Big Five 五大人格特质
5. 三年级数学能力评估框架
6. AB Test 交叉验证策略
7. 社会期望偏差检测与去伪存真技巧

### 模块 4：个性化教学系统 🔲 未开始

> **核心目标**：根据画像结果，为孩子量身定制数学学习方案。

#### 4.1 自适应题目生成
- 根据孩子当前的数学能力水平，动态生成难度合适的题目
- 视觉型孩子 → 配图题；动觉型孩子 → 操作题；游戏型孩子 → 闯关题
- 融入孩子的兴趣爱好（如奥特曼、乐高）作为题目背景

#### 4.2 教学策略引擎
- 成长型思维的孩子 → 可以直接挑战稍难的题目
- 固定型思维的孩子 → 先从简单题建立信心，逐步升级
- 容易挫败的孩子 → 错误时给予更多鼓励，降低失败感
- 好奇心强的孩子 → 加入开放性探索题

#### 4.3 进度追踪与报告
- 记录每次做题的对错、用时、情绪反应
- 定期生成学习报告给家长
- 薄弱知识点自动标注和专项练习

### 模块 5：系统架构升级 🔲 规划中

> **核心目标**：从"聪明的单体 Prompt"演进为专业的 Agent 架构。

#### Phase B：双 Agent 拆分（近期）
- **Agent 1 - 暖心老师**：只负责聊天回复，Prompt 极简，对话自然
- **Agent 2 - 幕后专家**：接收对话记录，专做深度分析和画像更新

#### Phase C：完整 Agent Framework（远期）
- Workflow 状态机编排（破冰 → 初评 → 深评 → 教学 → 复习）
- Skills/Tools（题库调用、可视化报告、知识图谱查询）
- 向量知识库 RAG（按需检索专家理论，而非全量注入）
- Memory 分层（短期/长期/工作记忆）
