## 一、项目愿景：打造真正的“数字导师”

本系统致力于创造一个具备深度共情与科学决策能力的 AI 教师，其核心使命是：
1. **全维洞察**：深入了解孩子的个性、行为特征、知识掌握度、行为动机及心理敏感点。
2. **战略规划**：基于 3-6 年级数学知识大纲，为孩子量身定制长短期学习目标与提升计划。
3. **精准交付**：提供符合孩子人格特征的课程、练习、任务与激励方案。
4. **动态优化**：通过持续评估能力现状，自动调优课程内容与教学路径，实现最高效的数学能力提升。

## 二、系统功能模块

### 模块 1：深度特征画像系统 (Profiling Agent) ✅ 已增强
- **维度扩展**：在基础四维度（个性、行为、学习方式、数学能力）基础上，增加“行为动机”与“敏感点”追踪。
- **动态量化**：引入 **BKT (Bayesian Knowledge Tracing)**，将知识掌握度从定性描述升级为定量掌握概率。
- **去伪存真**：利用心理学投射技术，识别孩子的社会期望偏差。

### 模块 2：战略规划系统 (Strategist Agent) 🔲 建设中
- **目标设定**：基于 `K12-Knowledge-Graph` 设定长期目标（学期）与短期任务（周/日）。
- **路径寻优**：根据孩子效率最高的学习方式（VARK）规划前置知识点回顾路径。
- **效能分析**：计算每个知识点的“习得半衰期”与“掌握能效比”。

### 模块 3：智能教学交互系统 (Teacher Agent) ✅ 已升级
- **双 Agent 协同**：
    - **暖心老师**：负责 100% 亲和力的前端交流与支架式引导（Scaffolding）。
    - **幕后专家**：负责后台静默分析与画像同步。
- **多模态交互**：集成语音识别 (STT) 与语音朗读 (TTS)。

### 模块 4：个性化内容与激励系统 🔲 规划中
- **内容适配**：基于兴趣点（Minecraft, 乐高）自动包装数学场景。
- **Skill 插件化**：
    - `mathgenerator`: 自动题目生成。
    - `report_generator`: 家长端深度诊断报告。
- **动态奖励机制**：根据孩子的性格（如成就动机型 vs 认可需求型）匹配不同的精神/物质激励。

## 三、核心技术栈与架构

### 3.1 核心算法与理论
- **知识追踪**: BKT (Bayesian Knowledge Tracing)
- **教学理论**: ZPD (最近发展区) + Scaffolding (支架式教学)
- **性格心理学**: Big Five (五大人格) + Erikson (发展阶段论)

### 3.2 架构演进
- **Workflow 编排**：破冰 -> 评测基线 -> 设定目标 -> 动态教学 -> 总结报告。
- **MCP Server**：将画像与知识图谱作为标准化资源暴露。
