# 工作流设计 (Workflow Design)

系统采用阶段化的评估工作流，通过已完成的评测项数量（`answered_count`）自动驱动状态流转。

## 1. 阶段定义

| 阶段名称 | 触发条件 | 核心任务 | AI 引导风格 |
|---------|---------|---------|------------|
| **破冰阶段 (Icebreak)** | `answered_count == 0` | 建立信任，获取姓名、年级、基本兴趣点。 | 极度温和，不抛出硬核题目。 |
| **基础评测 (Baseline)** | `0 < answered_count < 8` | 触发 SDQ、VARK、成长型思维等基础量表。 | 引导式，自然嵌入题目。 |
| **深度画像 (DeepDive)** | `answered_count >= 8` | 进行交叉验证，针对性地触发互动游戏（如工作记忆测试）。 | 挑战式，鼓励孩子尝试更高难度的任务。 |

## 2. 调度逻辑

1. **Teacher Agent**: 在每轮对话中，根据当前 `stage` 注入不同的 System Prompt。
2. **Analyst Agent**: 观察孩子在不同阶段的反应差异。
3. **UI 控制**: 侧边栏的进度条和状态标签会实时显示当前阶段。

## 3. 未来扩展
- **自定义流转**: 支持根据特定的“性格特征”进入不同的教学分支（如：对竞技性强的孩子进入“排位赛”模式）。
- **人工干预**: 允许家长/老师手动切换当前阶段。
